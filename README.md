Entry for the [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-the-printer-apology-60229153) bounty **"The Printer Apology"**: the funniest one-line apology from an office printer, 120 characters max.

`main.py` (stdlib only, deterministic) writes one line to `/output/entry.txt`:

> Sorry I ate your boarding pass. Cheap paper, a rogue staple, and you shouting like I'd filed for divorce.

Run it with `python3 main.py`.
